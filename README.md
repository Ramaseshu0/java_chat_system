# Java Chat System

This is a basic chat system project where two user interfaces can chat simultaneously. This project was built during my first year of college to explore foundational Java networking and socket programming.

The chat application introduces both ends simultaneous response.

How to run:
1. Open in VS Code or other IDEs
2. Run java server.java
3. Run java client.java
